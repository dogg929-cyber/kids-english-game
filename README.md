# Kids English Game 🐶🍎🌈

2〜5歳向けの、英語のことば（どうぶつ・いろ・くだもの・すうじ）を
楽しく覚えられるシンプルなWebゲームです。

日本語話者の未就学児が、保護者と一緒に（または一人でも）
タップと音声だけで遊べることを目指しています。

## 遊び方

1. **ホーム画面** で「どうぶつ / いろ / くだもの / すうじ」の
   いずれかを選ぶと、絵カード（フラッシュカード）で単語を学べます。
   - カードをタップ、またはスピーカーボタン🔊をタップすると
     英語の発音が流れます。
   - ◀ ▶ ボタンでカードを送れます。
2. **クイズであそぶ！** ボタンから、全カテゴリ混合の4択クイズに
   挑戦できます。英語の発音を聞いて、合う絵をタップします。
   正解すると効果音と紙吹雪でお祝いします。

## 特徴

- 文字が読めない年齢でも遊べるよう、絵（絵文字）と音声を中心に設計
- ボタンは大きく、誤タップしにくいレイアウト
- ブラウザ標準の `SpeechSynthesis`（音声合成）と `Web Audio API`
  （効果音）のみを使用し、外部サービス・画像素材への依存なし
- スマホ・タブレットでの利用を想定したレスポンシブデザイン

## 技術構成

- 素の HTML / CSS / JavaScript のみ（フレームワーク不使用）
- 依存パッケージなし・ビルド不要
- `index.html` / `style.css` / `app.js` の3ファイル構成

## ローカルでの実行方法

ビルド不要です。`index.html` をブラウザで直接開くか、
簡易サーバーを立てて開いてください。

```bash
# 例: Pythonの簡易サーバーを使う場合
python3 -m http.server 8000
# ブラウザで http://localhost:8000 にアクセス
```

## 対応環境について

- 音声合成（発音読み上げ）は端末・ブラウザにインストールされている
  英語音声に依存します。対応していない環境では、代わりに
  簡単な効果音が鳴ります。
- Chrome / Safari / Edge の最新版での動作を想定しています。
